Featured Project

Sovereign RAG on Bielik

Eskadra Bielik Mission 2

Problem

Organizations need AI systems that keep data sovereign — no external APIs, no data leaving the infrastructure. Most RAG solutions depend on OpenAI or cloud-only vector stores, creating vendor lock-in and compliance risk.

Approach

Built a fully sovereign RAG pipeline using Polish Bielik 4.5B model, EmbeddingGemma for 768-dim embeddings, and dual vector search (BigQuery online, Qdrant offline). Side-by-side UI compares raw Bielik vs Bielik + RAG responses.

Impact

Deployable via docker compose up or serverless on GCP with NVIDIA L4 GPU. Delivered as a hands-on workshop to 30 participants. Fully open-source.

Stack

Bielik 4.5B v3.0 EmbeddingGemma BigQuery Vector Search Qdrant FastAPI Ollama Cloud Run + L4 GPU Docker Compose
